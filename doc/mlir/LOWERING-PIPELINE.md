# MLIR Lowering Pipeline

**Related:** [../MLIR-COMPILATION-OVERVIEW.md](../MLIR-COMPILATION-OVERVIEW.md)

---

## Overview

This document describes the transformation stages as ONNX models are lowered through MLIR dialects to native code.

---

## Pipeline Stages

```
ONNX-MLIR        →        HIP Dialect      →      LLVM Dialect     →    Native Code
(MorphiZen)           (OnnxToHip pass)        (HipToLLVM pass)       (LLVM backend)
                                            (GenerateInterface pass)
```

---

## Stage 1: ONNX-MLIR (Input from MorphiZen)

**Input:** ONNX model file (`.onnx`)
**Output:** MLIR module with ONNX dialect, func, arith

**Example:**
```mlir
module {
  func.func @main(%arg0: tensor<1x3x224x224xf32>) -> tensor<1x64x224x224xf32> {
    %weights = arith.constant dense<[...]> : tensor<64x3x3x3xf32>
    %bias = arith.constant dense<[...]> : tensor<64xf32>

    %0 = "onnx.Conv"(%arg0, %weights, %bias) {
      kernel_shape = [3, 3],
      strides = [1, 1],
      pads = [1, 1, 1, 1],
      dilations = [1, 1],
      group = 1
    } : (tensor<1x3x224x224xf32>, tensor<64x3x3x3xf32>, tensor<64xf32>)
        -> tensor<1x64x224x224xf32>

    %1 = "onnx.Relu"(%0) : (tensor<1x64x224x224xf32>) -> tensor<1x64x224x224xf32>

    return %1 : tensor<1x64x224x224xf32>
  }
}
```

**Key characteristics:**
- High-level ONNX operations (`onnx.Conv`, `onnx.Relu`, etc.)
- Tensor types (`tensor<...>`)
- Constants inlined in code (`arith.constant`)
- Return value semantics

**Generated by:** MorphiZen framework (existing)

## Stage 2: HIP Dialect (After OnnxToHip Pass)

**Input:** ONNX-MLIR module
**Output:** HIP dialect module with func, memref, llvm.mlir.global

**Example:**
```mlir
module {
  // Constants extracted to globals
  llvm.mlir.global constant @constant_0(
    dense<[[[[1.0, ...]]]]> : tensor<64x3x3x3xf32>
  ) : !llvm.array<1728 x f32>

  llvm.mlir.global constant @constant_1(
    dense<[0.5, ...]> : tensor<64xf32>
  ) : !llvm.array<64 x f32>

  // Main function signature changed
  func.func @main(%ctx: !hip.context,
                   %input: memref<1x3x224x224xf32>,
                   %output: memref<1x64x224x224xf32>) -> i32 {

    // Retrieve constants from GPU state
    %weights = hip.get_constant(%ctx, 0) : (!hip.context, i64) -> memref<64x3x3x3xf32, 1>
    %bias = hip.get_constant(%ctx, 1) : (!hip.context, i64) -> memref<64xf32, 1>

    // ONNX operations replaced with HIP operations (inline, in-place)
    %temp = hip.alloc(%ctx) : memref<1x64x224x224xf32, 1>
    hip.conv(%ctx, %input, %weights, %bias, %temp) {
      kernel_shape = [3, 3],
      strides = [1, 1],
      pads = [1, 1, 1, 1],
      dilations = [1, 1],
      group = 1
    } : (!hip.context, memref<...>, memref<...>, memref<...>, memref<...>)

    // Destination-passing: copy result to output argument
    memref.copy %temp, %output : memref<1x64x224x224xf32, 1> to memref<1x64x224x224xf32>

    // Return success status
    %c0_i32 = arith.constant 0 : i32
    return %c0_i32 : i32
  }

  // Helper functions generated
  llvm.func @get_constant_count() -> i64 {
    %c4 = llvm.mlir.constant(2 : i64) : i64
    llvm.return %c4 : i64
  }

  func.func @initialize_constants(%ctx: !hip.context) -> i32 {
    // Upload all constants to GPU
    // (detailed implementation)
    %c0 = arith.constant 0 : i32
    return %c0 : i32
  }

  func.func @release_constants(%ctx: !hip.context) -> i32 {
    // Free GPU constant memory
    %c0 = arith.constant 0 : i32
    return %c0 : i32
  }
}
```

**Key changes:**
- **Operations:** `onnx.Conv` → `hip.conv`, `onnx.Relu` → `hip.relu`
- **Constants:** Moved from inline to `llvm.mlir.global`
- **State parameter:** Added `%ctx: !hip.context` to @main
- **Signature changed:**
  - Added output argument (destination-passing style)
  - Changed return to i32 status code
  - No longer returns tensor value
- **Inline structure:** All operations still in one function
- **Memref types:** GPU memory space (`, 1` = addrspace 1)
- **Constant helpers:** Generated for init/cleanup

**Generated by:** OnnxToHip pass (to be implemented in `lib/HipDialect/OnnxToHip.cpp`)

**Pass implementation:** Pattern-based rewriting using MLIR's conversion framework

## Stage 3: LLVM Dialect (After HipToLLVM Pass)

**Input:** HIP dialect module
**Output:** LLVM dialect module

**Example:**
```mlir
module {
  // Constants remain as globals
  llvm.mlir.global constant @constant_0(...) : !llvm.array<1728 x f32>
  llvm.mlir.global constant @constant_1(...) : !llvm.array<64 x f32>

  // Wrapper functions generated
  llvm.func @hip_conv_wrapper(
      %ctx: !llvm.ptr,
      %input: !llvm.struct<(ptr<1>, ptr<1>, i64, array<4xi64>, array<4xi64>)>,
      %weights: !llvm.struct<(ptr<1>, ptr<1>, i64, array<4xi64>, array<4xi64>)>,
      %bias: !llvm.struct<(ptr<1>, ptr<1>, i64, array<1xi64>, array<1xi64>)>,
      %output: !llvm.struct<(ptr<1>, ptr<1>, i64, array<4xi64>, array<4xi64>)>,
      %kernel_h: i64, %kernel_w: i64,
      %stride_h: i64, %stride_w: i64,
      // ... more parameters
  ) -> i32 {
    // Extract dimensions from memref structs (supports dynamic shapes!)
    %input_n = llvm.extractvalue %input[3, 0] : !llvm.struct<...> -> i64  // Runtime!
    %input_c = llvm.extractvalue %input[3, 1] : !llvm.struct<...> -> i64  // Runtime!
    %input_h = llvm.extractvalue %input[3, 2] : !llvm.struct<...> -> i64  // Runtime!
    %input_w = llvm.extractvalue %input[3, 3] : !llvm.struct<...> -> i64  // Runtime!

    // Extract data pointers
    %input_ptr = llvm.extractvalue %input[1] : !llvm.struct<...> -> !llvm.ptr<1>
    %weights_ptr = llvm.extractvalue %weights[1] : !llvm.struct<...> -> !llvm.ptr<1>
    %bias_ptr = llvm.extractvalue %bias[1] : !llvm.struct<...> -> !llvm.ptr<1>
    %output_ptr = llvm.extractvalue %output[1] : !llvm.struct<...> -> !llvm.ptr<1>

    // Get MIOpen handle from state
    %miopen_ptr = llvm.getelementptr %ctx[0, 1] : (!llvm.ptr) -> !llvm.ptr
    %miopen = llvm.load %miopen_ptr : !llvm.ptr

    // Create MIOpen descriptors
    %xDesc = llvm.call @miopenCreateTensorDescriptor(...) : ... -> !llvm.ptr
    llvm.call @miopenSet4dTensorDescriptor(%xDesc, %dataType,
                                            %input_n, %input_c, %input_h, %input_w)

    // ... create other descriptors

    // Call MIOpen
    %ret = llvm.call @miopenConvolutionForward(
      %miopen, %alpha_ptr,
      %xDesc, %input_ptr,
      %wDesc, %weights_ptr,
      %convDesc, %algo,
      %beta_ptr,
      %yDesc, %output_ptr,
      %workspace, %workspace_size
    ) : (...) -> i32

    // Cleanup descriptors
    llvm.call @miopenDestroyTensorDescriptor(%xDesc)
    // ...

    llvm.return %ret : i32
  }

  // Main function (modified signature)
  llvm.func @main(%ctx: !llvm.ptr,
                  %inputs: !llvm.ptr,   // Pointer to array of memref structs
                  %outputs: !llvm.ptr)  // Pointer to array of memref structs
                  -> i32 {

    // Load input memref struct from array
    %input_0_ptr = llvm.getelementptr %inputs[0] : (!llvm.ptr) -> !llvm.ptr
    %input_0 = llvm.load %input_0_ptr : !llvm.ptr -> !llvm.struct<...>

    // Load output memref struct from array
    %output_0_ptr = llvm.getelementptr %outputs[0] : (!llvm.ptr) -> !llvm.ptr
    %output_0 = llvm.load %output_0_ptr : !llvm.ptr -> !llvm.struct<...>

    // Get constants from state
    %weights_gpu = llvm.call @hip_get_constant(%ctx, %c0) : (!llvm.ptr, i64) -> !llvm.ptr<1>
    // ... build weights memref struct

    // Call wrapper (clean interface)
    %ret = llvm.call @hip_conv_wrapper(
      %ctx, %input_0, %weights_struct, %bias_struct, %temp_struct,
      3, 3,        // kernel_h, kernel_w
      1, 1,        // stride_h, stride_w
      1, 1, 1, 1,  // pads
      1, 1,        // dilations
      1            // group
    ) : (...) -> i32

    // ... more operations

    %c0_i32 = llvm.mlir.constant(0 : i32) : i32
    llvm.return %c0_i32 : i32
  }

  // Constant helpers (lowered to LLVM)
  llvm.func @initialize_constants(%ctx: !llvm.ptr) -> i32 {
    // Get global constant address
    %constant_0_addr = llvm.mlir.addressof @constant_0 : !llvm.ptr
    %constant_0_size = llvm.mlir.constant(6912 : i64) : i64  // 1728 × 4 bytes

    // Allocate GPU memory
    %gpu_ptr_ptr = llvm.alloca %c1 x !llvm.ptr : (i64) -> !llvm.ptr
    llvm.call @hipMalloc(%gpu_ptr_ptr, %constant_0_size) : (!llvm.ptr, i64) -> i32
    %gpu_ptr = llvm.load %gpu_ptr_ptr : !llvm.ptr

    // Copy to GPU
    llvm.call @hipMemcpy(%gpu_ptr, %constant_0_addr, %constant_0_size, %kind)
      : (!llvm.ptr, !llvm.ptr, i64, i32) -> i32

    // Store GPU pointer in context.gpu_constants[0]
    %gpu_constants_ptr_ptr = llvm.getelementptr %ctx[0, 3] : (!llvm.ptr) -> !llvm.ptr
    %gpu_constants = llvm.load %gpu_constants_ptr_ptr : !llvm.ptr
    %constant_0_slot = llvm.getelementptr %gpu_constants[0] : (!llvm.ptr) -> !llvm.ptr
    llvm.store %gpu_ptr, %constant_0_slot : !llvm.ptr

    // ... repeat for other constants

    %c0 = llvm.mlir.constant(0 : i32) : i32
    llvm.return %c0 : i32
  }

  llvm.func @release_constants(%ctx: !llvm.ptr) -> i32 {
    // Load GPU pointers and free
    %gpu_constants_ptr_ptr = llvm.getelementptr %ctx[0, 3] : (!llvm.ptr) -> !llvm.ptr
    %gpu_constants = llvm.load %gpu_constants_ptr_ptr : !llvm.ptr

    %constant_0_slot = llvm.getelementptr %gpu_constants[0] : (!llvm.ptr) -> !llvm.ptr
    %gpu_ptr = llvm.load %constant_0_slot : !llvm.ptr
    llvm.call @hipFree(%gpu_ptr) : (!llvm.ptr) -> i32

    // ... repeat for other constants

    %c0 = llvm.mlir.constant(0 : i32) : i32
    llvm.return %c0 : i32
  }
}
```

**Key changes:**
- **Types:** `!hip.context` → `!llvm.ptr`, `memref<...>` → struct-by-value
- **Operations:** `hip.conv` → `llvm.call @hip_conv_wrapper`
- **Wrapper functions:** Generated for each HIP operation
- **@main signature:** Changed to accept arrays of memref structs
- **Dynamic shapes:** Dimensions extracted from memref structs at runtime
- **State access:** Explicit `getelementptr` + `load`
- **Constant retrieval:** Load GPU pointers from context.gpu_constants array

**Generated by:** HipToLLVM pass (in `lib/HipDialect/HipToLLVM.cpp`)

**Pass implementation:**
- Convert HIP operations to wrapper calls
- Generate wrapper functions on-demand (reuse if exists)
- Lower types: !hip.context → !llvm.ptr
- Keep memrefs as struct-by-value (NOT unpacked)

## Stage 4: C Interface (After GenerateInterfacePass)

**Input:** LLVM dialect module with @main + constant helpers
**Output:** LLVM dialect module + C interface wrappers

**New functions generated:**

### inference_init
```mlir
llvm.func @inference_init(%out_state: !llvm.ptr<!llvm.ptr>) -> i32 {
  // 1. Allocate context (malloc)
  %context_size = llvm.mlir.constant(32 : i64) : i64  // sizeof(context struct)
  %context = llvm.call @malloc(%context_size) : (i64) -> !llvm.ptr

  // 2. Create GPU handles
  %stream_ptr = llvm.alloca %c1 x !llvm.ptr : (i64) -> !llvm.ptr
  llvm.call @hipStreamCreate(%stream_ptr) : (!llvm.ptr) -> i32
  %stream = llvm.load %stream_ptr : !llvm.ptr

  %miopen_ptr = llvm.alloca %c1 x !llvm.ptr : (i64) -> !llvm.ptr
  llvm.call @miopenCreate(%miopen_ptr) : (!llvm.ptr) -> i32
  %miopen = llvm.load %miopen_ptr : !llvm.ptr
  llvm.call @miopenSetStream(%miopen, %stream) : (!llvm.ptr, !llvm.ptr) -> i32

  %hipblas_ptr = llvm.alloca %c1 x !llvm.ptr : (i64) -> !llvm.ptr
  llvm.call @hipblasLtCreate(%hipblas_ptr) : (!llvm.ptr) -> i32
  %hipblas = llvm.load %hipblas_ptr : !llvm.ptr

  // 3. Store handles in context
  %stream_field = llvm.getelementptr %context[0, 0] : (!llvm.ptr) -> !llvm.ptr
  llvm.store %stream, %stream_field : !llvm.ptr
  // ... store miopen, hipblas

  // 4. Allocate gpu_constants array
  %count = llvm.call @get_constant_count() : () -> i64
  %ptr_size = llvm.mlir.constant(8 : i64) : i64
  %array_size = llvm.mul %count, %ptr_size : i64
  %gpu_constants = llvm.call @malloc(%array_size) : (i64) -> !llvm.ptr
  %gpu_constants_field = llvm.getelementptr %context[0, 3] : (!llvm.ptr) -> !llvm.ptr
  llvm.store %gpu_constants, %gpu_constants_field : !llvm.ptr

  // 5. Initialize constants
  %ret = llvm.call @initialize_constants(%context) : (!llvm.ptr) -> i32

  // 6. Return context via out parameter
  llvm.store %context, %out_state : !llvm.ptr

  llvm.return %ret : i32
}
```

### inference_compute
```mlir
llvm.func @inference_compute(%state: !llvm.ptr,
                              %inputs: !llvm.ptr,   // span_t*
                              %outputs: !llvm.ptr)  // span_t*
                              -> i32 {
  // 1. Parse span_t inputs
  %inputs_data_ptr = llvm.getelementptr %inputs[0, 0] : (!llvm.ptr) -> !llvm.ptr
  %inputs_data = llvm.load %inputs_data_ptr : !llvm.ptr  // tensor_t*

  // 2. Get first tensor
  %tensor_0 = llvm.getelementptr %inputs_data[0] : (!llvm.ptr) -> !llvm.ptr

  // 3. Extract tensor.data pointer
  %data_ptr_ptr = llvm.getelementptr %tensor_0[0, 0] : (!llvm.ptr) -> !llvm.ptr
  %data = llvm.load %data_ptr_ptr : !llvm.ptr

  // 4. Extract tensor.shape (CRITICAL: Runtime dimensions!)
  %shape_ptr_ptr = llvm.getelementptr %tensor_0[0, 1] : (!llvm.ptr) -> !llvm.ptr
  %shape_ptr = llvm.load %shape_ptr_ptr : !llvm.ptr  // int64_t*

  // 5. Load runtime dimensions
  %dim0_ptr = llvm.getelementptr %shape_ptr[0] : (!llvm.ptr) -> !llvm.ptr
  %dim0 = llvm.load %dim0_ptr : i64  // Runtime value!
  %dim1_ptr = llvm.getelementptr %shape_ptr[1] : (!llvm.ptr) -> !llvm.ptr
  %dim1 = llvm.load %dim1_ptr : i64  // Runtime value!
  // ... load all dimensions

  // 6. Calculate strides from runtime dimensions
  %stride3 = llvm.mlir.constant(1 : i64) : i64
  %stride2 = llvm.mul %dim3, %stride3 : i64  // Runtime calculation!
  %stride1 = llvm.mul %dim2, %stride2 : i64
  %stride0 = llvm.mul %dim1, %stride1 : i64

  // 7. Build memref struct
  %data_gpu = llvm.addrspacecast %data : !llvm.ptr to !llvm.ptr<1>
  %memref = llvm.mlir.poison : !llvm.struct<(ptr<1>, ptr<1>, i64, array<4xi64>, array<4xi64>)>
  %memref = llvm.insertvalue %data_gpu, %memref[0] : ...  // allocated_ptr
  %memref = llvm.insertvalue %data_gpu, %memref[1] : ...  // aligned_ptr
  %memref = llvm.insertvalue %c0, %memref[2] : ...        // offset
  %memref = llvm.insertvalue %dim0, %memref[3, 0] : ...   // size[0] = RUNTIME
  %memref = llvm.insertvalue %dim1, %memref[3, 1] : ...   // size[1] = RUNTIME
  // ... insert all sizes and strides (all runtime values!)

  // 8. Allocate array and store memref struct
  %input_array = llvm.alloca %c1 x !llvm.struct<...> : (i64) -> !llvm.ptr
  llvm.store %memref, %input_array : !llvm.ptr

  // 9. Do similar for outputs
  // ...

  // 10. Call @main with arrays of memref structs
  %ret = llvm.call @main(%state, %input_array, %output_array)
    : (!llvm.ptr, !llvm.ptr, !llvm.ptr) -> i32

  llvm.return %ret : i32
}
```

### inference_cleanup
```mlir
llvm.func @inference_cleanup(%state: !llvm.ptr) -> i32 {
  // 1. Release constants
  llvm.call @release_constants(%state) : (!llvm.ptr) -> i32

  // 2. Destroy handles
  %hipblas_ptr = llvm.getelementptr %state[0, 2] : (!llvm.ptr) -> !llvm.ptr
  %hipblas = llvm.load %hipblas_ptr : !llvm.ptr
  llvm.call @hipblasLtDestroy(%hipblas) : (!llvm.ptr) -> i32

  %miopen_ptr = llvm.getelementptr %state[0, 1] : (!llvm.ptr) -> !llvm.ptr
  %miopen = llvm.load %miopen_ptr : !llvm.ptr
  llvm.call @miopenDestroy(%miopen) : (!llvm.ptr) -> i32

  %stream_ptr = llvm.getelementptr %state[0, 0] : (!llvm.ptr) -> !llvm.ptr
  %stream = llvm.load %stream_ptr : !llvm.ptr
  llvm.call @hipStreamDestroy(%stream) : (!llvm.ptr) -> i32

  // 3. Free gpu_constants array
  %gpu_constants_ptr = llvm.getelementptr %state[0, 3] : (!llvm.ptr) -> !llvm.ptr
  %gpu_constants = llvm.load %gpu_constants_ptr : !llvm.ptr
  llvm.call @free(%gpu_constants) : (!llvm.ptr) -> ()

  // 4. Free context
  llvm.call @free(%state) : (!llvm.ptr) -> ()

  %c0 = llvm.mlir.constant(0 : i32) : i32
  llvm.return %c0 : i32
}
```

**Generated by:** GenerateInterfacePass (to be implemented)

**Critical for dynamic shapes:** `inference_compute` loads dimension values at runtime from tensor_t.shape

## Stage 5: Native Code (LLVM Backend)

**Input:** LLVM dialect module
**Output:** Native DLL

**Steps:**
1. Translate LLVM dialect → LLVM IR (`.ll`)
2. Compile LLVM IR → Object file (`.obj` / `.o`)
3. Link with HIP/MIOpen/hipBLAS → DLL (`.dll` / `.so`)

**Exported symbols:**
- `inference_init`
- `inference_compute`
- `inference_cleanup`

## TODO Items for Phase 2

### Memory Management Strategy

**Current (Phase 1):** Allocate/free in `inference_compute`
- Simple but slow (~20-65ms overhead)
- Use only for initial implementation

**Future (Phase 2):** Allocation hoisting
- Move allocations to `inference_init`
- Reuse pre-allocated buffers in `inference_compute`
- **4-12x speedup**

**See [MEMORY-MANAGEMENT.md](../MEMORY-MANAGEMENT.md) for detailed strategy.**

### Descriptor Caching

**Current:** Create descriptors on every `inference_compute` call
**Future:** Cache descriptors in state
- Create in `inference_init`
- Reuse in `inference_compute`
- Destroy in `inference_cleanup`

### Workspace Memory

**Current:** Allocate per-operation
**Future:** Pre-allocate workspace in `inference_init`
- Determine max size needed
- Allocate once
- Reuse across all operations
