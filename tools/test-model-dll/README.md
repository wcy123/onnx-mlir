# test-model-dll - Model DLL Testing Tool

## Purpose

`test-model-dll` is an end-to-end testing tool for validating compiled model DLLs generated by mlir-hip-compiler. It verifies DLL loading, interface exports, and inference execution without requiring GPU hardware (works with mock runtime).

## Use Cases

### 1. CI/CD Integration
Automated testing of compiled models:
```bash
mlir-hip-compiler model.mlir -o model.dll --from-onnx-mlir
test-model-dll model.dll --validate
```

### 2. Manual Verification
Test DLL after compilation:
```bash
test-model-dll path/to/model.dll --verbose --validate
```

### 3. Performance Benchmarking
Measure inference execution:
```bash
test-model-dll model.dll --iterations 100
```

## Command-Line Options

- `--verbose, -v` : Show tensor shapes, values, and timing
- `--validate` : Check output for NaN/Inf values
- `--iterations N` : Run N inference iterations (default: 1)
- `--help, -h` : Show usage information

## Test Validation

The tool performs these checks:
1. **DLL Loading** - Verifies DLL loads successfully
2. **Export Resolution** - All 3 interface functions found (inference_init/compute/cleanup)
3. **Execution** - init/compute/cleanup sequence runs without crashes
4. **Output Validation** - Optional NaN/Inf checks
5. **Performance** - Optional timing measurements

## Dependencies

- **C++17 compiler**
- **Platform DLL loading API** (LoadLibrary on Windows, dlopen on Linux)
- **No LLVM/MLIR/HIP dependencies** (completely standalone)

This makes test-model-dll extremely lightweight and portable.

## Comparison with Other Tools

**hip-opt:**
- Purpose: MLIR pass testing and debugging
- Input: MLIR files
- Output: Transformed MLIR
- Use when: Developing/debugging MLIR passes

**mlir-hip-compiler:**
- Purpose: Production DLL compilation
- Input: MLIR files
- Output: Compiled DLL
- Use when: Generating production artifacts

**test-model-dll:**
- Purpose: DLL testing and validation
- Input: Compiled DLL
- Output: Test results (PASSED/FAILED)
- Use when: Verifying compiled models work correctly

## Typical Workflow

```bash
# 1. Compile MLIR to DLL
mlir-hip-compiler demo.mlir -o demo.dll --from-onnx-mlir -v

# 2. Test the DLL
test-model-dll demo.dll --verbose --validate

# 3. Optional: Benchmark performance
test-model-dll demo.dll --iterations 1000
```

## Building

```bash
cmake -S . -B ../../build/$(basename $PWD) -DBUILD_TEST_MODEL_DLL=ON
cmake --build ../../build/$(basename $PWD) --config Debug --target test-model-dll
```
